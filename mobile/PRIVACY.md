# CargoResQ Driver privacy notice

The driver app collects the account identity, assigned vehicle, active shipment state, and precise location only when a driver chooses to report a breakdown. Location is sent to the CargoResQ API to coordinate rescue matching and is retained with the incident audit trail according to the carrier's data-retention policy.
